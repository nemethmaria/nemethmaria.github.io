Reviews, guides and the occasional note on clear writing

I write the reviews and guides at Online-Kaszino.net, a Hungarian site for readers who want straight answers before they decide anything.

This little page lives on GitHub because I'm also learning my way around code: Git, Markdown and the basics of how a web page is put together. It turns out a lot of it feels familiar to a writer. Drafts become commits, edits become diffs, and a good README is just a good introduction.

What I care about in both worlds is the same thing: say what something is, show how it works, and leave out the words that don't help.
